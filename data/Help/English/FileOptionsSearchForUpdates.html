Program options dialog page "Search for updates"

On this page you can define if and how often D-Fend Reborn should look for updates.

Program updates

The update checker asks GitHub for the latest release of D-Fend Reborn and offers to open its download page if there is a newer version (see details below).
(Default value for this option: "Only manual")

Add current version number to request URL

This option was used by the update check of the original D-Fend Reloaded; the update check of D-Fend Reborn (GitHub) does not use it.

Package lists update

From this box you can select if and when D-Fend Reborn should update the lists offered in the packages manager (the lists are downloaded from the D-Fend Reborn GitHub repository). The lists can also be updated via the "Update package lists" button in the package manager dialog at any time manually.
(Default value for this option: "Only manual")

Cheats database

From this box you can select if and when D-Fend Reborn should search and install updates to the cheats database (from the D-Fend Reborn GitHub repository).
(Default value for this option: "Only manual")

Search for updates now

Clicking this button opens the same dialog as the menu item Search for updates from the help menu.

Details on the function of the program update checker

The update checker asks GitHub for the latest release of D-Fend Reborn (https://github.com/Eldricos/D-Fend-Reborn/releases). If the version number of this release is bigger than the version number of the installed D-Fend Reborn, the update checker asks you if you want to install the new version. On Windows it then downloads the update installer of the release from GitHub and starts it; D-Fend Reborn is closed and started again after the update. On Linux (and if the update installer can not be used) the download page of the release is opened in your web browser.

The update checker does not transfer any of your private data to the internet; it only reads the information about the latest release (version number and files of the release) from GitHub.

The update checker does nothing else you would do when you look for updates. The update checker can automatically check for updates when D-Fend Reborn is started. But because many people do not like applications "phoning home" without their permission, this feature is turned off by default. (You can turn it on in the Search for updates page of the program options dialog. And you can manually start the update checker at any time by choosing "Search for updates..." from the "Help" menu.)
