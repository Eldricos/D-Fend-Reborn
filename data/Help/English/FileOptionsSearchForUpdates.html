Program options dialog page "Search for updates"

On this page you can define if and how often D-Fend Reborn should look for updates.

Program updates

The update checker asks GitHub for the latest release of D-Fend Reborn and offers to open its download page if there is a newer version (see details below).
(Default value for this option: "Only manual")

Add current version number to request URL

This option was used by the update check of D-Fend Reborn; the update check of D-Fend Reborn (GitHub) does not use it.

Package lists update

From this box you can select if and when D-Fend Reborn should update the lists offered in the packages manager. The lists can also be updated via the "Update package lists" button in the package manager dialog at any time manually.
(Default value for this option: "Only manual")

Cheats database

From this box you can select if and when D-Fend Reborn should search and install updates to the cheats database.
(Default value for this option: "Only manual")

Mobygames reader configuration update

From this box you can select when the function for reading game information from the Mobygames homaepage should update its configuration from the D-Fend Reborn homepage. To be able to react on changes of the Mobygames homepage the reader function is configurateable. On the D-Fend Reborn homepage there is always a file telling the reader how to interpret the Mobygames search result page to get the game information.
(Default value for this option: "On first use each day")

Search for updates now

Clicking this button opens the same dialog as the menu item Search for updates from the help menu.

Details on the function of the program update checker

The update checker asks GitHub for the latest release of D-Fend Reborn (https://github.com/Eldricos/D-Fend-Reborn/releases). If the version number of this release is bigger than the version number of the installed D-Fend Reborn, the update checker asks you if you want to download the new version and opens the download page of the release in your web browser. No program is downloaded or started by the update checker itself.

The update checker does not transfer any of your private data to the internet; it only reads the information about the latest release (version number and address of the download page) from GitHub.

The update checker does nothing else you would do when you look for updates. The update checker can automatically check for updates when D-Fend Reborn is started. But because many people do not like applications "phoning home" without their permission, this feature is turned off by default. (You can turn it on in the Search for updates page of the program options dialog. And you can manually start the update checker at any time by choosing "Search for updates..." from the "Help" menu.)
