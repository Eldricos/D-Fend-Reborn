Search for updates

By clicking this option you can manually look for updates for D-Fend Reborn. You can also configurate on the Search for updates page of the program options dialog to look for updates automatically at a chosen interval.

The update checker asks GitHub for the latest release of D-Fend Reborn (https://github.com/Eldricos/D-Fend-Reborn/releases). If the version number of this release is bigger than the version number of the installed D-Fend Reborn, the update checker asks you if you want to download the new version and opens the download page of the release in your web browser. No program is downloaded or started by the update checker itself.

The update checker does not transfer any of your private data to the internet; it only reads the information about the latest release (version number and address of the download page) from GitHub.

The update checker does nothing else you would do when you look for updates. The update checker can automatically check for updates when D-Fend Reborn is started. But because many people do not like applications "phoning home" without their permission, this feature is turned off by default. (You can turn it on in the Search for updates page of the program options dialog. And you can manually start the update checker at any time by choosing "Search for updates..." from the "Help" menu.)
