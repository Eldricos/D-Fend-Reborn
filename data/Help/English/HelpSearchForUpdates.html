Search for updates

By clicking this option you can manually look for updates for D-Fend Reborn. You can also configurate on the Search for updates page of the program options dialog to look for updates automatically at a chosen interval.

The update checker asks GitHub for the latest release of D-Fend Reborn (https://github.com/Eldricos/D-Fend-Reborn/releases). If the version number of this release is bigger than the version number of the installed D-Fend Reborn, the update checker asks you if you want to update. On Windows D-Fend Reborn then downloads the update installer of the new version (D-Fend-Reborn-x.y.z-UpdateSetup.exe) and starts it for the program folder (Windows asks for admin rights); D-Fend Reborn closes and is started again when the update is installed. This works for installed and portable copies. On Linux (and for a program folder without DFend.dat) the download page of the release is opened in your web browser instead.

The update checker does not transfer any of your private data to the internet; it only reads the information about the latest release (version number and addresses of the download page and of the update installer) from GitHub.

The update checker does nothing else you would do when you look for updates. The update checker can automatically check for updates when D-Fend Reborn is started. But because many people do not like applications "phoning home" without their permission, this feature is turned off by default. (You can turn it on in the Search for updates page of the program options dialog. And you can manually start the update checker at any time by choosing "Search for updates..." from the "Help" menu.)
