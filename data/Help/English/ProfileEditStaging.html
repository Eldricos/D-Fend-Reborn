Profile editor dialog page "DOSBox Staging"

This page contains settings of DOSBox Staging, the DOSBox included with D-Fend Reborn, that older DOSBox versions do not have. They are only used if DOSBox Staging is selected for the profile (on the DOSBox settings page); otherwise they are greyed out. "default" leaves the choice to DOSBox Staging (the setting is not written to the DOSBox configuration file). In the classic profile editor these settings are on the tab "DOSBox Staging"; for several profiles at once use Extras | Edit multiple profiles (section "DOSBox Staging").

  • Shader ([render] shader): how the picture is scaled to the window or screen. crt-auto (default of DOSBox Staging) emulates a CRT monitor matching the video mode of the game, crt-auto-machine a monitor matching the emulated video card, crt-auto-arcade / crt-auto-arcade-sharp an arcade monitor with thick scanlines; sharp gives sharp pixels without blur, bilinear a smooth image, nearest unfiltered pixels. Other shaders of DOSBox Staging can be entered by name (e.g. scaler/xbr-lv3). This replaces the scalers of DOSBox 0.74.
  • Integer scaling ([render] integer_scaling): only scale by whole numbers (vertical, horizontal), auto (for the CRT shaders) or off.
  • Viewport size ([render] viewport): the maximum area used for the picture: fit (window or screen), a size like 1280x960 or a percentage of the desktop like 80%.
  • CGA composite monitor emulation ([composite] composite): NTSC composite colours for CGA, PCjr and Tandy games: auto, on or off.
  • 3dfx Voodoo emulation ([voodoo] voodoo): emulation of a 3dfx Voodoo graphics card (needs a fast computer).
  • CPU cycles for protected mode programs ([cpu] cpu_cycles_protected): speed of the emulated CPU for protected mode (32 bit) programs: auto (the same as the CPU cycles of the profile), max or a number. If this is "default", D-Fend Reborn sets it from the CPU cycles of the profile ("auto" in DOSBox 0.74 means 3000 cycles for real mode and max for protected mode).
  • Reduce the CPU cycles if the computer is too slow ([cpu] cpu_throttle): for fixed cycles values.
  • Reverb ([mixer] reverb): room effect for the sound: tiny, small, medium, large, huge (on = medium).
  • Chorus ([mixer] chorus): chorus effect for the synthesizer channels: light, normal, strong.
  • Crossfeed ([mixer] crossfeed): mixes the left and the right channel of OPL / Game Blaster music a bit (better with headphones): light, normal, strong.
  • Parallel port sound device ([speaker] lpt_dac): disney (Disney Sound Source), covox (Covox Speech Thing), ston1 (Stereo-on-1) or none. If this is "default", the Disney Sound Source setting of the profile is used.
  • IBM PS/1 Audio ([speaker] ps1audio): emulation of the IBM PS/1 Audio card.
  • SoundFont for FluidSynth ([fluidsynth] soundfont): the SoundFont (.sf2) used if the MIDI device of the profile is fluidsynth: a file or the name of a SoundFont in the soundfonts folder of DOSBox Staging.
  • Roland MT-32 model ([mt32] model): the model used if the MIDI device of the profile is mt32 (cm32l, mt32, mt32_old, mt32_new or an exact version like mt32_204).
  • Folder with the Roland MT-32 ROM files ([mt32] romdir): the folder with the MT-32 / CM-32L ROM files (otherwise the mt32-roms folder of DOSBox Staging is used).
  • Mouse capture ([mouse] mouse_capture): onclick (capture the mouse when clicking into the window), onstart, seamless (move the mouse freely between DOSBox and the desktop) or nomouse. If this is "default", the "Auto lock mouse" setting of the profile is used.

A value chosen here takes precedence over the value D-Fend Reborn derives from the settings of the other pages (e.g. "Mouse capture" over "Auto lock mouse"). Further DOSBox Staging settings can be entered as custom settings on the DOSBox settings page (e.g. [render] and monochrome_palette=green in two lines).
