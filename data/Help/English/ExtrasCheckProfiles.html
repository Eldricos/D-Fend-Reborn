Menu:   Extras | Check profiles for not existing files

Check profiles for not existing files

Clicking this menu item will check all profiles for missing files (for example if the game file you have defined to start exists etc.) and folders. If there are missing files it will show a list of all profiles with missing files and the names of the missing files. The mounted folders and image files of the profiles are checked as well.

To find games that were moved to another folder, or to delete the profiles of uninstalled games, use Extras | Find missing games.
