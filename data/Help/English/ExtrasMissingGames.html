Find missing games

Games imported from GOG or Steam stay in the folders of these stores. If a game is uninstalled there, or moved to another folder or drive (for example when a Steam library is moved), its profile points to files that do not exist any more. The same can happen with any other game whose folder was moved or deleted.

This dialog lists all profiles whose program file, setup program, mounted folders or image files (for ScummVM games: the game folder) are missing. The column "Not found" shows the first missing file; hold the mouse over it to see all of them. Select the games to work on with the check boxes:

  • Search new location: select the folder the games are in now. This can be the game folder itself, a folder containing the game folders (e.g. the new GOG Games folder) or a Steam library (its folder or steamapps\common). If a game is found there, all paths of its profile (program files, drives, extra files and folders) are changed to the new location; the settings of the profile stay as they are. Games that are not found are listed and keep their profiles unchanged.
  • Delete profiles: deletes the profiles of the selected games, e.g. of games that were uninstalled. Only the profiles are deleted; no game files are touched.

Physical CD drives mounted in a profile are not checked (they are only available while a disc is inserted).
