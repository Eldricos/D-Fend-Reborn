First run wizard

The first run wizard will help you to initially setup D-Fend Reborn.

Program language and DOSBox language

The program and the DOSBox language will initially be chosen from the setup program so in most cases this two fields will already show the right language. (On Linux, where there is no setup program, the program language is chosen according to the language of the system.)

DOSBox installation to be used by default

In this field you can choose which DOSBox installation should be used by default to run the DOS games. If you did not explicitly deselect the option to install DOSBox when installing D-Fend Reborn on Windows, you can keep the setting "Version installed with D-Fend Reborn" (DOSBox Staging). Independent of the default installation chosen here you can assign an individual DOSBox version to each profile later.

On Linux DOSBox is not included with D-Fend Reborn; install DOSBox Staging (or DOSBox) with the package manager. If the DOSBox folder chosen here does not contain DOSBox, D-Fend Reborn uses the dosbox program found in the search path.

Automatically check for updates

Via this checkbox you can choose whether D-Fend Reborn should look for updates automatically. (The update checker will only search for updates and inform you about new versions, it will never automatically install any update without asking you.) If you keep to default setting D-Fend Reborn will never connect to the internet automatically. You can look for updates manually at any time via the Search for updates function from the help menu.

You can change all settings later at any time via the program options dialog.
