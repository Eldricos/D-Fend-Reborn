Import archive file

With this function you can import archive file based complete profiles (including all game files), plain archive files and archive files made with DBGL into D-Fend Reborn. You can create archive files via the Make archive package function of the "Profile" menu.

On Linux the 7-Zip command line program (7z, 7za or 7zz, package p7zip or 7zip) has to be installed for reading zip and 7z files. (On Windows it is included with D-Fend Reborn.)

Import via drag&drop

You can also import archive files by just dragging them from the file manager (for example the Windows Explorer) to the D-Fend Reborn program window.
