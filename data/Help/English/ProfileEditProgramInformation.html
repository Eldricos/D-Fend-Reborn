Profile editor dialog page "Program information"

On this page you can define many additional game information like genre, developer etc. The information entered on this page are shown in the games list (in view mode report) and the profiles can be filtered by them.

Via the "Look up game at ..." you can search for the profile name on different classic game related search engines.

Look up game information

The button "Look up game information" searches the game information (name, genre, developer, publisher, year, notes) for the profile name and inserts the values you select. Two data sources can be chosen in the dialog:

  • D-Fend Reborn auto setup templates (offline): the game information of the more than 1600 auto setup templates included in D-Fend Reborn. No internet connection is needed.
  • Wikidata (internet): the free database Wikidata (the data base of Wikipedia). The search can be limited to DOS games. Wikidata is not always complete for DOS games - please check the values. Only the game name is sent to Wikidata.

If the profile has no web site yet, the web site of the game (or its Wikipedia / Wikidata page) is inserted as well. The data source chosen last is used again next time.

Missing or wrong game information can be improved in the auto setup templates. Templates for new games and corrected templates can be submitted on GitHub, see Auto setup templates.
