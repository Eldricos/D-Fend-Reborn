Program options dialog page "General"

There are two checkboxes on this page:

  • Minimize to tray area
    If this option is activated, the D-Fend Reborn program window will be visible in minimized state as an icon in the tray area (the area next to the clock on the right side of the taskbar) instead of a normal taskbar record. (On Linux the icon is shown in the tray area of the desktop environment. Some desktops, for example GNOME without a tray extension, have no tray area; there the window is only minimized normally.)
    (Default value for this option: off)
  • Start with Windows (*)
    If this checkbox is checked, D-Fend Reborn will be started together with Windows. On Linux an autostart entry (~/.config/autostart/D-Fend Reborn.desktop) is created instead, so D-Fend Reborn is started when you log in to the desktop.
    (Default value for this option: off)
  • Allow only one running instance (*)
    Allows only one instance of D-Fend Reborn running at the same time. If D-Fend Reborn is started while an instance is already running, this running instance is just sent to foreground.
    (Default value for this option: on)

The options marked with (*) are only visible in advanced mode.
