Operation mode

This dialog will show you the operation mode D-Fend Reborn has been installed in. D-Fend Reborn can be installed in three different operation modes:

  • User directory mode
    This is the default operation mode of the Windows setup program. The program files of D-Fend Reborn and DOSBox will be installed to a subdirectory of your program files directory. When runnding D-Fend Reborn no write access to this directory is needed any more. (This means you can run the program without having admin rights.) The profiles, settings and games will be stored in the a subdirectory named "D-Fend Reborn" of your user profile directory (%USERPROFILE%\D-Fend Reborn).
  • Program directroy mode
    This mode is only offered for compability with D-Fend (classic). The program files of D-Fend Reborn and DOSBox will be installed to a subdirectory of your program files directory. This directory will also be used for profiles, setting and your game files. This means you will need to have write access to this directory when running D-Fend Reborn.
  • Portable mode
    This mode mostly behaves like "Program directory mode" but the base directory and the path to DOSBox etc. will be stored relatively to the program directory. This means you can copy the program directory to any location and everything will be ok. (This is ment for running D-Fend Reborn and DOSBox directly from USB sticks etc.)

The operation mode is stored in the file DFend.dat in the program folder (USERDIRMODE, PRGDIRMODE or PORTABLEMODE). On Linux there is no setup program: Without a DFend.dat file D-Fend Reborn works in program directory mode and keeps all data next to the program. If DFend.dat contains USERDIRMODE, the profiles, settings and games are stored in ~/.local/share/D-Fend Reborn/.

The checkboxes and (read-only) edit fields in this dialog will show you the information described above, too.
