GitHub issues

Problems with D-Fend Reborn, bug reports and suggestions can be posted on the issues page of the D-Fend Reborn project on GitHub:

https://github.com/Eldricos/D-Fend-Reborn/issues

Please describe what you did, what happened and what you expected, and name your operating system (Windows or Linux) and the D-Fend Reborn version (menu Help | About).

Many problems are not problems of D-Fend Reborn but of running a game inside DOSBox. If a game does not run, try to run it in DOSBox without any frontend first. The DOSBox conf file of a profile (which D-Fend Reborn can create via the context menu of a profile or from the profile editor) is helpful when asking for help. Questions about running old games in DOSBox can also be asked on the Vogons ("Very old games on new systems") forum: https://www.vogons.org/
