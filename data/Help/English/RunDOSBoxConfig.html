Menu:   Run | Open DOSBox configuration file

Open DOSBox configuration file

This menu item will open the DOSBox default configuration file in an editor. You can run DOSBox with this configuration file via the Run DOSBox menu item from the "Run" menu.

For DOSBox 0.73 and newer this is the DOSBox user configuration file (if it exists): on Windows %LOCALAPPDATA%\DOSBox\dosbox-version.conf, on Linux ~/.dosbox/dosbox-version.conf or ~/.config/dosbox/dosbox-version.conf. Otherwise the dosbox.conf file from the DOSBox directory is opened. DOSBox Staging uses its configuration file dosbox-staging.conf: in the DOSBox folder (portable copies of D-Fend Reborn), otherwise on Windows %LOCALAPPDATA%\DOSBox\dosbox-staging.conf and on Linux ~/.config/dosbox/dosbox-staging.conf. DOSBox-X uses dosbox-x.conf in its folder.

The default DOSBox configuration file from the DOSBox directory has no meaning for D-Fend Reborn. It will no be used when creating profile. You can change the configuration file template for new profiles via the Templates menu item from the "Extras" menu.
