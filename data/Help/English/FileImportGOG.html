Import GOG games

DOS games bought at GOG.com come with their own DOSBox and DOSBox configuration files. This function creates D-Fend Reborn profiles for these games, so they can be started with the DOSBox of D-Fend Reborn (DOSBox Staging) and managed like all other games. The game files stay where GOG (or GOG Galaxy) has installed them; nothing is copied.

Select the folder of one game (e.g. C:\GOG Games\Duke Nukem 3D) or the folder with all your GOG games (e.g. C:\GOG Games or C:\Program Files (x86)\GOG Galaxy\Games; Linux: ~/GOG Games). All DOS games found in it are imported; games that are already in the games list (same name or a program file in the game folder) are skipped. Games for Windows are ignored.

For every game the profile gets:

  • the name of the game and its GOG icon,
  • the settings of the DOSBox configuration files of GOG (e.g. full screen, CPU cycles, sound card),
  • the folders and CD images GOG mounts (e.g. the game.ins / game.gog CD image) as drives,
  • the program file of the game and its parameters, and the setup program (from the "Settings" start entry of GOG).

Some GOG games start with a menu (e.g. to choose between two games or languages). For these the commands of GOG are kept in the autoexec section of the profile, and they replace the normal start of the game ("Profile editor", page "DOS environment").

Some games are sold by GOG with ScummVM instead of DOSBox (e.g. Beneath a Steel Sky, Flight of the Amazon Queen, Lure of the Temptress). These games get a ScummVM profile: the game ID and the data folder come from the ScummVM configuration file of GOG, and the game is started with the ScummVM set in the program options.

The folders are found via the goggame-*.info file of the game (Windows) or via the files dosbox*.conf and dosbox*_single.conf next to a dosbox folder (Linux and older GOG versions).
