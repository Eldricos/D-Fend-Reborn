Import Steam games

Many DOS games sold on Steam come with their own DOSBox and DOSBox configuration files, like the games of GOG.com. This function creates D-Fend Reborn profiles for these games, so they can be started with the DOSBox of D-Fend Reborn (DOSBox Staging) and managed like all other games. The game files stay in the Steam library; nothing is copied.

Select the folder of one game (e.g. ...\steamapps\common\Wolfenstein 3D) or a Steam library: the Steam folder, a library folder or its steamapps\common folder. The dialog starts in the first Steam library found on this computer (the libraries are listed in Steam's file steamapps\libraryfolders.vdf). All DOS games found are imported; games that are already in the games list are skipped. The names of the games are taken from Steam (appmanifest_*.acf files).

The DOSBox configuration files of a Steam game can have any name; they are searched in the game folder and its subfolders (e.g. base or DOSBox-0.74). The configuration file that mounts the game and starts it is used; variants for the setup program (setup or settings in the name) give the setup program of the profile, variants for network games are ignored. Settings in a dosbox.conf next to it are imported as well. Everything else works as described for GOG games: drives, program file, parameters, games starting with a menu and games using ScummVM.

Steam games whose start options are only stored in Steam itself (DOSBox started without configuration file) cannot be recognized; use the profile wizard for these.
