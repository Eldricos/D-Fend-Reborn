Menü:   Extras | Verknüpfungen für mehrere Profile gleichzeitig erstellen

Verknüpfungen erstellen

Mit Hilfe dieser Funktion können Sie ein Verknüpfungen für die gewählten Profile auf dem Desktop oder im Startmenü erstellen. Wenn Sie diese Verknüpfungen später anklicken, wird das entsprechende Profil automatisch gestartet.

Unter Linux werden die Verknüpfungen statt als Windows-.lnk-Dateien als .desktop-Starterdateien auf dem Desktop bzw. im Anwendungsmenü (~/.local/share/applications) angelegt.

Wenn Sie die Windows-Version von D-Fend Reborn in einer Wine-Umgebung unter Linux einsetzen, können Sie diese Funktion so umkonfigurieren, dass sie statt Windows-Verknüpfungen Linux Shell-Skripte erstellt. (Sie dafür die Dialogseite Wine-Unterstützung des Programmeinstellungen-Dialogs.)
