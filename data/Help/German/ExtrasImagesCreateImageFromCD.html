ISO-Image von CD erstellen

In diesem Dialog können Sie ISO-Imagedateien von bestehenden CD-ROMs erstellen. ISO-Images können über die Dialogseite Laufwerke des Profileditor-Dialogs als Laufwerke in DOSBox eingebunden werden.

Der D-Fend Reborn ISO-Image-Leser kann nur den jeweils ersten Track einer CD lesen. Wenn Sie ein ISO-Image einer CD, die mehrer Tracks besitzt, erstellen wollen, sollten Sie einen externen ISO-Image-Leser verwenden.

Unter Linux werden die Laufwerke mit einem Laufwerksbuchstaben und der zugehörigen Gerätedatei angezeigt (z.B. D: /dev/sr0). Wenn Sie keine Berechtigung für den direkten Zugriff auf die Gerätedatei haben, lässt D-Fend Reborn sie über udisks2 öffnen (die Desktop-Umgebung fragt dabei eventuell nach Ihrem Passwort).
