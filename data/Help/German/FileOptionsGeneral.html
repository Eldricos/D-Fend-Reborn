Programmeinstellungen-Dialogseite "Allgemein"

Auf dieser Seite gibt es zwei Optionen, die aktiviert oder deaktiviert werden können:

  • In den Benachrichtigungsbereich minimieren
    Wenn diese Option aktiviert ist, wird das D-Fend Reborn Programmfenster im minimierten Zustand nicht in der Taskleiste angezeigt, sondern nur als kleines Symbol im Benachrichtigungsbereich unmittelbar links neben der Uhrzeit ganz unten rechts auf dem Bildschirm. (Unter Linux wird das Symbol im Benachrichtigungsbereich der Desktop-Umgebung angezeigt. Manche Desktops, z.B. GNOME ohne entsprechende Erweiterung, haben keinen Benachrichtigungsbereich; dort wird das Fenster nur normal minimiert.)
    (Vorgabewert für diese Option: deaktiviert)
  • Mit Windows starten (Linux: Bei der Anmeldung starten) (*)
    Wenn diese Funktion aktiviert ist, wird D-Fend Reborn bei jedem Windows-Start automatisch mitgestartet. Unter Linux wird stattdessen ein Autostart-Eintrag (~/.config/autostart/D-Fend Reborn.desktop) angelegt, so dass D-Fend Reborn bei der Anmeldung am Desktop gestartet wird.
    (Vorgabewert für diese Option: deaktiviert)
  • Nur eine laufende Instanz des Programms zulassen (*)
    Ist diese Option aktiviert, so kann immer nur eine Instanz von D-Fend Reborn zurzeit laufen. Wird eine weitere Instanz des Programmes gestartet, so wird lediglich die bereits laufende Instanz von D-Fend Reborn in den Vordergrund geholt.
    (Vorgabewert für diese Option: aktiviert)

Die mit (*) gekennzeichneten Optionen sind nur sichtbar, wenn der Konfigurationsmodus "Vollständig" gewählt ist.
