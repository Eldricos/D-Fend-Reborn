Nach Updates suchen

Durch das Anklicken dieses Menüpunkts starten Sie eine manuelle Suche nach Updates für D-Fend Reborn. Sie können auf der Nach Updates suchen Dialogseite des Programmeinstellungen-Dialogs auch einstellen, dass D-Fend Reborn in regelmäßigen Abständen automatisch nach Updates sucht.

Die Update-Überprüfung fragt bei GitHub die neueste Version von D-Fend Reborn ab (https://github.com/Eldricos/D-Fend-Reborn/releases). Wenn die Versionsnummer dieser Version größer ist als die Versionsnummer der installierten D-Fend Reborn Version, fragt die Update-Überprüfung, ob Sie die neue Version herunterladen möchten, und öffnet die Download-Seite der Version in Ihrem Webbrowser. Die Update-Überprüfung selbst lädt keine Programme herunter und startet auch keine Programme.

Die Update-Überprüfung überträgt keine persönlichen Daten ins Internet; sie liest lediglich die Informationen über die neueste Version (Versionsnummer und Adresse der Download-Seite) von GitHub.

Der Update-Checker stellt also lediglich eine Automatisierung dessen dar, was Sie manuell unternehmen würden, wenn Sie auf der Homepage nach Updates suchen. Die Update-Überprüfung kann automatisch beim Programmstart von D-Fend Reborn durchgeführt werden. Da Programme, die ungefragt Internetverbindungen aufbauen, häufig jedoch nicht gern gesehen werden, ist diese Option im Auslieferungszustand deaktiviert. (Sie können sie auf der Nach Updates suchen-Seite des Programmeinstellungen-Dialogs aktivieren. Außerdem können Sie die Update-Überprüfung jederzeit über den Menüpunkt "Nach Updates suchen..." im Menü "Hilfe" starten.)
