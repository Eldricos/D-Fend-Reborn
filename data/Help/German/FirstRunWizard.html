Erststart-Assistent

Der Erststart-Assistent hilft Ihnen bei Vornehmen der wichtigten Einstellungen unmittelbar nach der Installation von D-Fend Reborn.

Programmsprache und DOSBox-Sprache

Die Programm- und DOSBox-Sprache wird vom Installationsprogramm übernommen, so dass diese in den meisten Fällen bereits korrekt eingestellt sein sollte. (Unter Linux, wo es kein Installationsprogramm gibt, wird die Programmsprache gemäß der Sprache des Systems gewählt.)

Standard DOSBox-Installation

In diesem Feld können Sie angeben, welche DOSBox-Installation standardmäßig zum Aufruf der DOS-Spiele verwendet werden soll. Sofern Sie bei der Installation von D-Fend Reborn unter Windows die Option, DOSBox mit zu installieren, nicht explizit abgewählt haben, können Sie die Einstellung "Mit D-Fend Reborn installierte Version" (DOSBox Staging) beibehalten. Unabhängig von der hier gewählten Standard-Installation können Sie später jedem Profil auch eine individuelle DOSBox-Version zuweisen.

Unter Linux wird DOSBox nicht mit D-Fend Reborn ausgeliefert; installieren Sie DOSBox Staging (oder DOSBox) über die Paketverwaltung. Enthält das hier gewählte DOSBox-Verzeichnis kein DOSBox, so verwendet D-Fend Reborn das im Suchpfad gefundene Programm dosbox.

Automatisch nach Updates suchen

Über dieses Feld können Sie festlegen, ob D-Fend Reborn automatisch in regelmäßigen Abständen nach Programmupdates suchen soll. (Es wird dabei nur nach Updates gesucht; wenn ein Update gefunden wurde, werden Sie gefragt, ob Sie dieses installieren wollen. Eine automatische Installtion von Updates ohne Rückfrage erfolgt keinesfalls.) Wenn Sie die Vorgabeeinstellungen beibehalten, wird D-Fend Reborn niemals automatisch Verbindungen mit dem Internet aufnehmen. Sie können auch jederzeit manuell über den Menüpunkt Nach Updates suchen im "Hilfe"-Menü einen Update-Suchvorgang starten.

Alle hier angebotenen Einstellungen können Sie auch später jederzeit in dem Programmeinstellungen-Dialog anpassen.
