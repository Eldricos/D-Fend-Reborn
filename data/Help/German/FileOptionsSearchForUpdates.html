Programmeinstellungen-Dialogseite "Nach Updates suchen"

Auf dieser Dialogseite können Sie einstellen ob und wie oft D-Fend Reborn nach Updates suchen soll.

Programm-Updates

Die Update-Überprüfung fragt bei GitHub die neueste Version von D-Fend Reborn ab und bietet an, deren Download-Seite zu öffnen, wenn es eine neuere Version gibt (siehe Details unten).
(Vorgabewert für diese Option: "Nur manuell")

Kennung der aktuellen Version in die Abfrage-URL integrieren

Diese Option wurde von der Update-Überprüfung von D-Fend Reborn verwendet; die Update-Überprüfung von D-Fend Reborn (GitHub) verwendet sie nicht.

Paketlisten aktualisieren

In diesem Feld kann gewählt werden, ob und wann D-Fend Reborn die Listen der im Paketmanager angeboten Pakete aktualisieren soll. Die Listen können auch jeder Zeit über die Funktion "Paketlisten aktualisieren" im Paketmanager manuell aktualisiert werden.
(Vorgabewert für diese Option: "Nur manuell")

Cheats-Datenbank

In diesem Feld können Sie auswählen, ob D-Fend Reborn automatisch nach Updates für die Cheats-Datenbank suchen soll.
(Vorgabewert für diese Option: "Nur manuell")

Mobygames-Downloader Konfigurationsupdate

In diesem Feld kann gewählt werden, wann die Funktion zum Auslesen von Spieleinformationen von der Mobygames-Homepage die Konfiguration neu von der D-Fend Reborn Homepage lesen soll. Um auf Änderungen an der Mobygames-Homepage reagieren zu können, ist es notwendig, dass die Ausleseroutinen konfigurierbar sind. Auf der D-Fend Reborn Homepage befindet sich eine Datei, die der Auslesefunktion mitteilt, wie die Mobygames-Suchanfrage-Antwortseiten auszuwerten sind um an die Spieleinformationen zu gelangen.
(Vorgabewert für diese Option: "Täglich bei der ersten Benutzung")

Jetzt nach Update suchen

Diese Schaltfläche öfnnet den Dialog, der auch über den Menüpunkt Nach Updates suchen im "Hilfe"-Menü erreichbar ist.

Dateils zur Funktionsweise der Programmupdate-Überprüfung

Die Update-Überprüfung fragt bei GitHub die neueste Version von D-Fend Reborn ab (https://github.com/Eldricos/D-Fend-Reborn/releases). Wenn die Versionsnummer dieser Version größer ist als die Versionsnummer der installierten D-Fend Reborn Version, fragt die Update-Überprüfung, ob Sie die neue Version herunterladen möchten, und öffnet die Download-Seite der Version in Ihrem Webbrowser. Die Update-Überprüfung selbst lädt keine Programme herunter und startet auch keine Programme.

Die Update-Überprüfung überträgt keine persönlichen Daten ins Internet; sie liest lediglich die Informationen über die neueste Version (Versionsnummer und Adresse der Download-Seite) von GitHub.

Der Update-Checker stellt also lediglich eine Automatisierung dessen dar, was Sie manuell unternehmen würden, wenn Sie auf der Homepage nach Updates suchen. Die Update-Überprüfung kann automatisch beim Programmstart von D-Fend Reborn durchgeführt werden. Da Programme, die ungefragt Internetverbindungen aufbauen, häufig jedoch nicht gern gesehen werden, ist diese Option im Auslieferungszustand deaktiviert. (Sie können sie auf der Nach Updates suchen-Seite des Programmeinstellungen-Dialogs aktivieren. Außerdem können Sie die Update-Überprüfung jederzeit über den Menüpunkt "Nach Updates suchen..." im Menü "Hilfe" starten.)
