Profileditor-Dialogseite "Programminformationen"

Auf dieser Dialogseite können Sie diverse Zusatzinformationen (wie z.B. Genre, Entwickler, usw.) zu jedem Profil erfassen. Die Informationen, die Sie auf dieser Seite angeben, werden in der Spieleliste im Ansichtsmodus Details angezeigt und außerdem kann die Spieleliste nach diesen Daten gefiltert werden.

Über die "Spiel nachschlagen bei ..." Schaltfläche können Sie auf mehreren, teilweise auf alte Spiele spezialisierten Suchmaschinen nach Informationen zu dem gewählten Spiel suchen.

Spielinformationen suchen

Die Schaltfläche "Spielinformationen suchen" sucht die Spielinformationen (Name, Genre, Entwickler, Publisher, Jahr, Notizen) zum Profilnamen und übernimmt die ausgewählten Werte. Im Dialog können zwei Datenquellen gewählt werden:

  • Auto-Setup-Vorlagen von D-Fend Reborn (offline): die Spielinformationen der über 1600 Auto-Setup-Vorlagen, die D-Fend Reborn enthält. Es wird keine Internetverbindung benötigt.
  • Wikidata (Internet): die freie Datenbank Wikidata (die Datenbank der Wikipedia). Die Suche kann auf DOS-Spiele beschränkt werden. Wikidata ist für DOS-Spiele nicht immer vollständig - bitte prüfen Sie die Werte. An Wikidata wird nur der Spielname übertragen.

Hat das Profil noch keine Webseite, wird außerdem die Webseite des Spiels (bzw. seine Wikipedia- oder Wikidata-Seite) eingetragen. Die zuletzt gewählte Datenquelle wird beim nächsten Mal wieder verwendet.

Fehlende oder falsche Spielinformationen können in den Auto-Setup-Vorlagen verbessert werden. Vorlagen für neue Spiele und korrigierte Vorlagen können auf GitHub eingereicht werden, siehe Auto-Setup-Vorlagen (englisch).
